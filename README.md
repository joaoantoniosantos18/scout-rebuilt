# Scout REBUILT

App de scouting para a temporada FRC 2026 **REBUILT**. Página única (HTML/CSS/JS puro), feita pra celular.

**Acesse:** https://joaoantoniosantos18.github.io/scout-rebuilt/

## O que tem
- **Partida:** Pré → Auto → Teleop → Endgame → Final, com contador de fuel (+1/+3/+5/+10 e desfazer), relógio da partida e indicador de HUB ativo/inativo por shift.
- **Pit:** tração, Trench/Bump, shooter, capacidade, escalada máxima, função.
- **Dados:** ranking por pontos/fuel/auto/torre/passes/piloto/defesa, ficha da equipe e simulador de aliança com os limites de RP (Team Update 22).
- **Exportar:** copia uma planilha (TSV) pra colar no Google Sheets/Excel; backup/import em JSON pra juntar dados de vários aparelhos.

Os dados ficam salvos no navegador de cada aparelho (localStorage).
